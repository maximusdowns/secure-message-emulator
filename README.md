# Secure Message Emulator

A Java-based secure messaging application being developed as a hands-on software engineering project.

## Current Goals

- Java 21
- Maven build and dependency management
- Git version control
- JUnit and Test Driven Development
- SOLID design principles

## Planned Development

The project will be developed incrementally to include:

- Swing desktop client
- Spring Boot REST service
- Persistent message storage
- Client/server networking
- TLS-secured communications
- Cucumber/Gherkin acceptance testing
- Continuous integration and automated code-quality checks
